# Marxalad 2 · Linux

> Linux waxaa ku shaqeeya adeegayaal badan oo internetka ku xiran. Barashada terminal-ka iyo maamulka Linux waxay kaa caawinaysaa inaad fahanto nidaamyada ay xirfadlayaasha amnigu maalin kasta la shaqeeyaan.

---

## 🎯 Hadaf

Inaad awood u yeelato isticmaalka terminal-ka Linux, maaraynta faylasha iyo rukhsadaha, iyo fahamka adeegyada aasaasiga ah.

## 📚 Mawduucyada la baranayo

| Mawduuc | Amarro tusaale ah |
|---|---|
| Hagidda faylasha | `pwd`, `ls`, `cd`, `find` |
| Akhrinta iyo maaraynta faylasha | `cat`, `less`, `head`, `tail`, `touch`, `mkdir`, `cp`, `mv`, `rm` |
| Raadinta qoraalka | `grep`, `locate`, `which` |
| Rukhsadaha faylasha | `chmod`, `chown`; akhri, qor, fuli (read/write/execute) |
| Isticmaalayaasha | `sudo`, `su`, users iyo groups |
| Hababka shaqaynaya (processes) | `ps`, `top`, `kill`, `systemctl` |
| Xaaladda shabakadda | `ip a`, `ss`, `netstat` |
| Xiriirka fog | `ssh user@host` — ku tababar mashiin aad leedahay ama shaybaar fasax leh |
| Bash | Amarro taxan iyo qoraallo fudud; eeg Marxaladda 3 |

Linux ma aha wax qarsoon; waa nidaam hawlgal oo leh habab iyo amarro aad ku baran karto ku celcelin.

### Sida Linux loogu tijaabiyo adigoon khatar gelin nidaamkaaga

1. Ku rakib VirtualBox: [virtualbox.org](https://www.virtualbox.org).
2. Soo dejiso Ubuntu ama Kali Linux bogga rasmiga ah.
3. Ku dhex rakib mashiin dalwad ah (virtual machine). Ha ku beddelin nidaamka kombiyuutarkaaga ilaa aad taqaanid waxa aad samaynayso.

## ✅ Liiska hubinta

- [ ] Waxaan terminal-ka ku adeegsaday `ls`, `cd`, `cat` iyo `grep`.
- [ ] Waxaan sharxi karaa rukhsadaha `rwx` iyo tusaale `chmod 755`.
- [ ] Waxaan fahmay waxa `sudo` u qabto iyo sababta aan si taxaddar leh u isticmaalo.
- [ ] Waxaan eegay process-yada anigoo adeegsanaya `ps` ama `top`.
- [ ] Waxaan ku xirmay mashiin tababar oo SSH adeegsanaya.
- [ ] Waxaan dhammaystiray ugu yaraan heerarka 0–20 ee Bandit.
