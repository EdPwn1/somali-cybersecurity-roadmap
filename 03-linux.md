# Marxalad 2 · Linux

> Server-yada adduunka badankood waxay Linux ka shaqeeyaan. Cybersecurity-ga wax badan wuxuu ku dhacaa terminal-ka Linux. Halkan waxaad baranaysaa nidaamka faylasha, amarrada, iyo bash-ka — adigoo ciyaaraya game bilaash ah!

---

## 🎯 Hadaf
Noqo mid aqoon u leh Linux: terminal-ka, nidaamka faylasha, permissions, iyo maamulka server-yada.

## 📚 Waxa La Barta

| Mawduuc | Amaarrada |
|---|---|
| Socodka (navigation) | `pwd`, `ls`, `cd`, `find` |
| Faylasha | `cat`, `less`, `head`, `tail`, `touch`, `mkdir`, `rm`, `cp`, `mv` |
| Raadinta | `grep`, `locate`, `which` |
| Permissions | `chmod`, `chown`, iyo r-x-w (read/write/execute) |
| Isticmaalayaasha | `sudo`, `su`, users, groups |
| Process-yada | `ps`, `top`, `kill`, `systemctl` |
| Shabakadda Linux | `ip a`, `ss`, `netstat` |
| SSH | `ssh user@host` (masuul ka galka server-yada) |
| Bash scripting | Sheeko-yar (variables, loops) — arag Marxalad 3 |

**Fiiro:** Linux maaha wax khiyaano ah — waa nidaam sida Windows ah oo qalab dheeraad ah. Daqiiqado gudahood waxaad helaysa inay ka fiican tahay.

## ✅ Liiska Hubinta

- [ ] Waan isticmaalay terminal-ka adigoon welwel lahayn (ls, cd, cat, grep)
- [ ] Waan fahmay permissions (`chmod 755`, rwx)
- [ ] Waan garanayaa `sudo` iyo maxay tahay
- [ ] Waan arkay process-yada (`ps aux`) oo aan dilay mid (`kill`)
- [ ] Waan ku xiranayaa server SSH (`ssh`)
- [ ] **Waan dhammaystiray Bandit levels 0-20** (ugu yaraan)
