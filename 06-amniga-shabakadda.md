# Marxalad 5 · Amniga shabakadaha iyo adeegyada daruuraha

> Marka aad fahanto aasaaska webka, waxaad sii baran kartaa sida loo qiimeeyo amniga shabakadaha iyo adeegyada daruuraha. Ku tababar oo keliya nidaamyo aad leedahay ama shaybaarro si cad loo oggolaaday.

---

## 🎯 Hadaf

Baro hababka aasaasiga ah ee qiimaynta amniga shabakadda, faham Active Directory, oo baro fikradaha bilowga ah ee AWS.

## 📚 Mawduucyada la baranayo

### Qiimaynta amniga shabakadda

| Mawduuc | Waxa aad baranayso ama qalab tusaale ah |
|---|---|
| Scanning | `nmap` oo lagu ogaado adeegyada mashiin shaybaar ah |
| Enumeration | Fahamka adeegyada SMB, FTP, SSH iyo webka ee shaybaarrada |
| Vulnerability scanning | Nuclei iyo Nessus Essentials; faham natiijooyinka ka hor intaadan ku tiirsanaan |
| Metasploit | Aasaaska framework-ka iyo ku tababarka mashiinno loogu talagalay |
| Password security | Fahamka hash-yada iyo sida loo ilaaliyo; ku tijaabi xog tijaabo ah oo keliya |
| Active Directory | Domain, users, groups iyo hordhaca Kerberos |
| Difaaca iyo adkaynta | Rukhsadaha, adeegyada iyo dejimaha nidaamka |

### Amniga adeegyada daruuraha (cloud)

| Mawduuc | Waxa aad baranayso |
|---|---|
| AWS | EC2, S3 iyo IAM (users, roles, policies) |
| Dejimaha khaldan | Sababta kaydka dadweynaha ama rukhsadaha xad-dhaafka ahi khatar u yihiin |
| Azure iyo GCP | Baro fikradaha guud marka aad AWS aasaaskiisa fahanto |

## ✅ Liiska hubinta

- [ ] Waxaan `nmap` ku baadhay mashiin shaybaar ah, natiijadana waan sharxi karaa.
- [ ] Waxaan fahmay adeegyada iyo ports-ka la ogaaday.
- [ ] Waxaan ku tababartay mashiin bilow ah oo TryHackMe ama Hack The Box ah.
- [ ] Waxaan garanayaa fikradaha aasaasiga ah ee Active Directory.
- [ ] Waxaan baray EC2, S3 iyo IAM gudaha cashar ama akoon tijaabo oo ammaan ah.
- [ ] Waxaan fahmay sababta loo xaddido rukhsadaha cloud-ka.

## ⏱️ Waqtiga qiyaasta ah

6–8 toddobaad, iyadoo ku xiran heerka aad joogto iyo waqtiga aad heli karto.

## 🏁 Hawsha lagu hubinayo horumarka

Dhammaystir dhowr mashiin oo bilow ah oo ku jira TryHackMe ama Hack The Box, kuna qor qoraal sharxaya waxa aad ka baratay. Adeegyada daruuraha, ku tababar koorso ama deegaan tijaabo oo aad maamusho; ha baarin akoon ama adeeg qof kale leeyahay.
