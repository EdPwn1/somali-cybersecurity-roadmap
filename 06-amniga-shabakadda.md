# Marxalad 5 · Amniga Shabakadda & Cloud-ka

> Ka dib markaad web-ka fahamto, waxaad bilaabayso hubinta nidaamyada buuxa — server-yada, shabakadaha gudaha, iyo cloud-ka. Halkan waxaad baranaysaa nmap, enumeration, Active Directory, iyo AWS aasaaska.

---

## 🎯 Hadaf
Noqo mid hubiya nidaamyada shabakadda: ka scanning-ka illaa exploitation-ka, iyo aasaaska cloud security-ga.

## 📚 Waxa La Barta

### Amniga shabakadda (network pentesting)
| Mawduuc | Qalabyada |
|---|---|
| Scanning | `nmap` (ports, services, versions) |
| Enumeration | SMB, FTP, SSH, web dirs (ffuf) |
| Vulnerability scanning | `nuclei`, Nessus Essentials (bilaash) |
| Exploitation | Metasploit aasaaska |
| Password attacks | `hydra`, hashcat |
| Active Directory (AD) | Users, groups, Kerberos basics |
| Privilege escalation | Linux/Windows (sudo misconfigs, services) |
| Pivoting | Gudaha shabakadda ka dib markaad heshid hal machine |

### Cloud security (aasaas)
| Mawduuc | Waxa |
|---|---|
| AWS basics | EC2, S3, IAM (users, roles, policies) |
| Cloud misconfigs | Public S3 buckets, IAM over-permission |
| Azure/GCP | Hoos ka fiiri (AWS marka hore) |

## ✅ Liiska Hubinta

- [ ] Waan isticmaalay `nmap` (`-sV`, `-sC`, `-p-`) oo aan sharxi karaa natijada
- [ ] Waan isticmaalay `ffuf` directory fuzzing
- [ ] Waan fahmay Metasploit aasaas (msfconsole, exploit, payload)
- [ ] Waan gudbay lab machine oo dhan (THM/HTB easy)
- [ ] Waan garanayaa AD aasaas (domain, users, Kerberos)
- [ ] Waan abuuray akoon AWS free tier (EC2, S3, IAM)
- [ ] Waan arkay public S3 bucket dhaawaca (flAWS.cloud)
