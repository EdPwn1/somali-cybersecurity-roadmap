# Marxalad 6 · Difaaca (Blue Team / SOC)

> Difaaca waa dhinaca kale ee cybersecurity-ka. SOC analyst-yada ayaa arka weerararka maalinlaha oo difaaca. Waa hawlo badan oo shaqo la heli karo — haddii aad jeclayso falanqaynta (analysis) more than weerarka, waddadani waa mid ka fiican!

---

## 🎯 Hadaf
Baro sida loo falanqeeyo log-yada, loo isticmaalo SIEM, iyo sida incident-ka (weerarka) loo maareeyo.

## 📚 Waxa La Barta

| Mawduuc | Waxa |
|---|---|
| Log-yada | Windows Event Logs, Linux logs, web server logs |
| SIEM | Splunk, Elastic (marka hore faham fikradda) |
| Alerting | Calaamadaha (indicators) oo aan la beddelin |
| Phishing analysis | Iimayl-xaaraan: headers, links, attachments |
| Incident response | Hel → xiro → nadiifi → soo celin |
| Threat intel | IOC-yada (IP, domain, hash) |
| Tools | Wireshark (dib u fiiri), VirusTotal, MITRE ATT&CK |

**MITRE ATT&CK** waa encyclopedia-ga weerarayaasha — tactics & techniques kasta. Haddii aad fahamto, waad hadashay luuqadda SOC-ga. [attack.mitre.org](https://attack.mitre.org)
