# Marxalad 6 · Difaaca (Blue Team iyo SOC)

> Amniga internetku kuma koobna tijaabinta difaacyada. Kooxaha difaacu waxay la socdaan nidaamyada, baaraan digniinaha, kana jawaabaan dhacdooyinka amni. Haddii aad jeceshahay falanqaynta iyo xalinta dhibaatooyinka, waddadan ayaa kugu habboonaan karta.

---

## 🎯 Hadaf

Baro aasaaska falanqaynta diiwaannada (logs), SIEM, iyo ka-jawaabidda dhacdooyinka amni.

## 📚 Mawduucyada la baranayo

| Mawduuc | Waxa aad baranayso |
|---|---|
| Diiwaannada (logs) | Windows Event Logs, Linux logs iyo diiwaannada server-ka webka |
| SIEM | Sida Splunk ama Elastic loogu ururiyo looguna falanqeeyo logs |
| Digniinaha | Sida loo kala saaro digniinta saxda ah iyo tan been-abuurka ah |
| Falanqaynta phishing-ka | Hubinta email-ka, headers-ka, xiriiriyeyaasha iyo lifaaqyada |
| Ka-jawaabidda dhacdooyinka | Ogaansho, xakamayn, nadiifin iyo soo-kabasho |
| Threat intelligence | Indicators of Compromise (IOC), sida IP, domain iyo file hash |
| Qalab | Wireshark, VirusTotal iyo MITRE ATT&CK |

**MITRE ATT&CK** waa saldhig aqooneed nidaamiya farsamooyinka ay adeegsadaan weeraryahannadu. Fahamkiisu wuxuu kaa caawinayaa inaad weerarrada u aqoonsato si isku nidaamsan. [attack.mitre.org](https://attack.mitre.org)

## ✅ Liiska hubinta

- [ ] Waxaan akhriyey dhacdooyin ku jira Windows Event Viewer ama Linux logs.
- [ ] Waxaan sharxi karaa waxa SIEM yahay iyo sida uu logs u ururiyo.
- [ ] Waxaan falanqeeyey tusaale email phishing ah.
- [ ] Waxaan VirusTotal ku eegay file hash tijaabo ah.
- [ ] Waxaan dhammaystiray ugu yaraan hal xaalad tababar oo LetsDefend ah.
- [ ] Waxaan garanayaa ujeeddada guud ee MITRE ATT&CK.

## ⏱️ Waqtiga qiyaasta ah

4–6 toddobaad, haddii aad wax barato qiyaastii hal saac maalintii.

## 🏁 Hawsha lagu hubinayo horumarka

Dhammaystir saddex xaaladood oo tababar ah oo ku jira LetsDefend ama Blue Team Labs Online. Mid kasta ka qor waxa dhacay, calaamadaha kuu muujiyey, iyo tallaabooyinka difaaca ee habboon.
